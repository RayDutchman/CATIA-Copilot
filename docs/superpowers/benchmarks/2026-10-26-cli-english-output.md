# CLI 英语输出契约

## 已确认边界

- CLI 自建的 help/schema、错误、异常、提示、进度、日志、安装器 notice 直接使用英语，不引入 i18n、语言开关或运行时翻译层。
- 用户数据、业务属性键和值、CATIA/系统原始消息保持原文；不会将中文路径或属性值改成英语。
- 用户接受 GUI 复用业务消息时显示英语；GUI 自身菜单和按钮不改。
- CLI 导出使用原始业务列键作为英文标准表头，Source 保留原始代码。GUI 显示表头仍复用原有映射；此为数据表示选择而非语言选项。

## 实施与验证原则

- 修改 CLI 入口、任务系统、安装器、schema 以及 CLI 可达业务模块的固定消息。
- BOM 自定义枚举、DescriptionRef/DescriptionInst 文档和末段属性名规则等未提交改动一并保留。
- 旧21工具的历史指纹文件不变；已替换的2项BOM仍由业务回归覆盖，其他19项按精确 AST 路径文案白名单还原后校验。仅8个函数的35条字符串被授权变化；未知字符串及逻辑变动仍使测试失败。
- 新增英文帮助/schema、业务失败、安装器提示及BOM英文标准表头回归；保留中文用户数据断言。
- 几何算法和建模契约的中文断言调整为对应英语语义，保留原约束检查。
- 用户原有 part_templates 改动不属于本任务，不修改、不提交。
